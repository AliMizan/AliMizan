### Nano-vLLM · W8A16 Quantization

<img src="https://img.shields.io/badge/Throughput-445%20%E2%86%92%201%2C016%2B%20tok%2Fs-7F1D1D?style=for-the-badge"/>
<img src="https://img.shields.io/badge/Weight%20VRAM-%7E50%25%20Lower-991B1B?style=for-the-badge"/>
<img src="https://img.shields.io/badge/Kernel-Triton-0B0B0B?style=for-the-badge&logoColor=DC2626"/>
<img src="https://img.shields.io/badge/Quantization-INT8%20W8A16-7F1D1D?style=for-the-badge"/>

</div>

Implemented and optimized **INT8 Weight-Only quantization** in Nano-vLLM.

- Custom **Triton GEMM kernel**
- Static tile configuration tuning
- Investigated dynamic tensor allocation overhead
- Investigated Triton JIT recompilation
- **1,016+ tok/s** benchmark
- **~50% reduction in weight VRAM**
- Opened an **upstream PR** to Nano-vLLM
